# Data Classification

## Classification

All application records must be fictional and synthetic.

## Prohibited data

The project must never contain:

- Real patient names
- NHS numbers
- Medical record numbers
- Real addresses
- Real telephone numbers
- Real email addresses
- Real appointment information
- Clinical notes
- Personally identifiable information
- Production healthcare data

## Synthetic identifiers

Approved examples:

- `SYN-PAT-0001`
- `APT-2026-0001`
- `demo-reception-user`
- `Cardiology Demonstration Clinic`

## Public disclaimer

The application interface and project documentation must display:

`DEMONSTRATION PLATFORM — SYNTHETIC DATA ONLY`
